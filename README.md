# Rampesna Homebrew Tap

Homebrew tap for [monitc](https://github.com/Rampesna/monitc) — a cross-platform server monitoring & DevOps management desktop application.

## Installation

```bash
brew tap Rampesna/tap
brew install --cask monitc
```

## Update

```bash
brew upgrade --cask monitc
```

## Uninstall

```bash
brew uninstall --cask monitc
```
